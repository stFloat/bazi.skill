## 二、按主题归类（学习时按这个顺序读）

### 主题 A：用神"清而薄"四连（310 / 255 / 320 / 319）

这四个盘是同一类病的四种表现，**建议连着读，体会评级的一致性**：

| 案例 | "薄"的成因 | 具体表现 |
|---|---|---|
| 310 | **无源 + 无护卫** | 午火为印，但生它者被克、护它者不见 |
| 255 | **日主担不起** | 丙火为用，但日主弱不受生 |
| 320 | **药本身质量差** | 己土为用，但己土卑湿，制水力弱 |
| 319 | **官印无根** | 有官有印，但都站不住 |

**共性结论**：这四盘都不是"没有用神"，而是"用神在，但兑现不了"。麦穗对这类的断语都往下压一层，且都**提前标出会引动灾祸的流年**。

**复用写法**：
> "用神是 ___，但 ___（薄因）。所以不是没有机会，是机会来了守不住。降一层论。需要特别留意 ___ 年（忌神当值/用神被冲），那一年 ___。"

### 主题 B：先运后格（择时 50 / 52 / 53 / 54）

四期择时共同演示了麦穗最反直觉的习惯：**原局漂亮但大运逆行 → 直接淘汰，理由不是"不好"，是"格越纯摔得越重"**。

- 52 期：丙辰、丁巳、戊午三个时辰原局成从强格，但大运一路水木 → 排除。
- 50 期：标题直接叫"仅考虑原局好选，结合大运难选"。
- 53/54 期：同一日同时辰池，男命女宝结论相反 → 性别决定大运方向，方向决定吉凶。

**复用写法**：
> "这个盘原局是 ___ 格，看起来很纯。但大运 ___。特殊格局要求格局与大运同向，现在方向相反——所以**不能按成格论**，要按 ___ 论。格越纯，摔得越重。"

### 主题 C：断语的时间点写法（317 / 187 / 308）

三篇都给了**唯一解式**的时间点，而不是列举年份：

- 317："唯己未运 2027 丁未年有婚期"
- 187："至迟丙午年（2026）必离"
- 308："26–27 年必婚灾与负债"

**为什么敢这么写**：因为触发条件是**结构性的**——某星到位 + 某宫被冲/被合，两个条件同时满足的年份在十年内通常只有一两个。

**复用写法**：
> "条件 A（用神/妻星到位）与条件 B（宫位被引动）同时成立的年份，在 ___ 运内只有 ___ 年。"

### 主题 D：断错了怎么复盘（136）

136 断"婚期必在戊午运 27 岁后"，实为 20 岁早婚、32 岁离。

**这不是纯失误，是可学的一课**：早婚发生在用神未到之时，等于"逆用神而动"，所以婚姻本身注定不稳，最终在 32 岁（近戊午运前）破裂——**结果反而印证了"正位在戊午"的判断**。

**复盘纪律**：断错时先分清三种情况——
1. 结构判错（看错病/用神）→ 需修方法。
2. 结构对但应期错（时间点偏了）→ 方法可接受，精度待提。
3. 结构对但用户行为改变了轨迹 → 不算错，记录即可。

## 三、本机案例：己卯 乙亥 甲戌 甲戌（男，1999-11-18 戌时，北京昌平）

这是本技能建立时唯一有**真实反馈**的案例，可作为校准基线。
完整推演见工作区 `八字推演_己卯乙亥甲戌甲戌_v2_skill版.md`（v2 为 skill 版，修正 6 处）。

**定盘**：北京时间 20:00 → 真太阳时 **19:59:23**（经度 −15.08 分，均时差 +14.46 分），距戌时边界 59 分钟，**低风险，时柱甲戌确认**。

**四柱**：己卯 / 乙亥 / 甲戌 / 甲戌　日主甲木，男命逆排，**起运 3 岁 7 个月**（约 2003 年 6 月）。

**神煞**：羊刃卯 · 桃花卯 · 华盖戌 · 天乙贵人未（辛未运）· **空亡申酉**

| 项 | 判断 |
|---|---|
| 旺衰 | **偏强（评分 11.1）**，旺在比劫而非印（木 3.6 vs 水 1.0）。三者俱备但未到旺极，因**卯被两戌争合**牵制了羊刃 |
| 病 | **比劫夺财**，三形态同现：贴身劫（乙克己）+ 合被隔断（甲己合被乙隔）+ 财坐受克（己坐卯）。三问检验：**无制（辛藏+申酉空）、无泄（火仅0.6）、会被引动（2027/2032）→ 重病** |
| 用神 | **丁火为主**（调候+泄旺+生财，一物三用）、**辛金为辅**（制劫护财）、庚金备用（待庚午运） |
| 评级 | **清而薄**。四项薄因占三项：藏支不透 + 无源 + **被贴身克（亥中壬邻克戌中丁）**。铁证：**用神所属之火 0.6，是全盘最弱一行** |
| 一句话 | 木旺成林，土薄被伐；**财与药共处一库 —— 欲开其财，必动其药** |
| 大运转机 | **庚午（43–52）**，七杀制劫 + 午戌半合火 + 火生戌土，两病同去，三样全实 |
| 辛未运（33–42） | **官星虚透、比劫争财**：辛官透干，但坐未而**亥卯未三合木局**把未土合走，官星失根 → 名分看似有了，实则被合去，是"有名无实"的十年；同时木局使比劫更旺，争财更凶 |
| 关键流年 | 2026 丙午（食伤泄秀进财，克辛官则求名不利）／2027 丁未（**亥卯未三合**，忌合伙借贷）／**2029 己酉（正财透干 + 酉冲卯羊刃，动而生财/成家）**／**2030 庚戌（本运唯一三样俱全之年**：庚制劫+第三财库+卯戌合火）／2031 辛亥（辛官透，亥亥自刑主内耗） |

**反馈**：当事人口述"你说的很多都是对的"（未逐项核对，属**部分印证**，不是全项校准）。

**这个案例贡献了什么新东西**（已回流进 `maisui.md`）：
1. **比劫夺财三种形态**——原手册只有"夺财"一个笼统说法，此案拆出了三种可分辨的结构。
2. **财分两笔的实用推论**——正财被劫 + 偏财入库 → "涨薪改善不了处境，置产才行"，这是可执行建议的来源。
3. **真太阳时的实际必要性**——此例经度差 −15.08 与均时差 +14.46 几乎抵消（净 −0.62 分），属巧合；但换到喀什（−161 分）就直接掉两个时辰。**不能因为一次巧合就省掉校正。**
4. **边界余量的量化标准**——时辰宽 2 小时，正中即 60 分钟余量；余量 <30 分钟必须并列两版。此标准写入 `truesolar.py`。
5. **争合必须先查再定旺衰**——卯同时被亥（半合木局）和两戌（六合化火）争夺，导致羊刃凶性不全放。**漏掉争合会把身强判高一档**（此盘若只算亥卯合，当断旺极，结论会重得多）。
6. **空亡越界的反例（已撤回，反面教材）**——本案例第二版曾用"申酉空亡"把壬申运判成"杀印双虚"、把 2029 己酉降为"雷声大雨点小"、把 2030 说成"别的年份都虚所以珍贵"，甚至把婚期从 2029 推到 33 岁后。**这是把旬空当断运主据，违反本派"神煞只作辅助意象"的规矩，已全部撤回。** 见下文"三·补"。
7. **一神多用清单法**——把丁火三项功能拆开逐项查，才发现"两项打折"，这是"清而薄"评级的具体来源。

**已知未验证项**（后续可回访校准）：
- 癸酉运（13–22 岁）求学阶段是否有明显挫折或转向（酉空 + 冲卯）。
- 妻星"争妻 / 差一步"之象是否成立。
- 2026 丙午"进财年"是否兑现。
- 辛未运"争夺加剧"是否成立（此条由本版修正得出，与 v1 相反，是重点校准对象）。
- 庚午运转机是否在 43 岁前后显现。

**两处需要留意的技术分歧**：

1. **取格**：脚本按"月令本气"给 **偏印格**（亥藏壬甲，壬为本气）；但时干**甲木比肩透出**，按《子平真诠》"透者取格"应取**比肩/月劫类**。两格之争不影响主断——取偏印格则病在枭印夺食（壬克丁），取月劫格则病在比劫夺财，**本盘两种情况同时成立**（壬克丁、乙克己）。记录此例是提醒：`bazi.py` 的 `pattern` 只是本气初步格，**必按透干规则重定**。

2. **调候**：脚本 `tiaohou` 给"寒（冬月），喜丙火、戊土"，是**通用冬月规则**；但《穷通宝鉴》甲木十月（亥月）专属用法是**庚金劈甲、丁火引丁**。校验层在此处应**覆盖脚本输出**，改取庚丁——而庚金恰好在 43 岁庚午运透干，运来补用，意义明确。**这是"脚本调候是通用值、需按日主五行查专属用神"的实例。**

## 三·补、空亡越界与撤回（本案例最重要的一课）

第二版把旬空当成了断运主据，连带改掉应期。**与麦穗原派不一致的，一律以原派为准。** 撤回对照：

| 项 | v2（空亡主断，已撤回） | 原派（结构主断） | 为什么改 |
|---|---|---|---|
| **壬申运 23–32** | 杀印双空，"想动而不得动" | **有制之运**：申中庚金七杀制乙劫（本运唯一天然制劫之物），壬水偏印坐申得生，**杀印相生**→压力转成资历；申亥害主奔波、动而不安 | 七杀制劫是本盘唯一现成的药，空亡不能把"有制"改写成"无制" |
| **2029 己酉** | 空冲，雷声大雨点小 | **正财透干 + 酉冲卯（冲开羊刃）**：财星到位且被冲动，主动而生财、感情落定；冲羊刃防奔波与意外，但属"动"，不属"虚" | 财透 + 冲动，是应期成立的**正面**组合 |
| **婚期** | 宜晚婚，33 岁后 | **唯 2029 己酉最实**，次选 2030 庚戌（财库 + 庚制乙，宜定不宜追） | 男命婚期看财星到位并取唯一解 |
| **辛未运 33–42** | 官劫对峙 | **官星虚透**：辛坐未，而亥卯未三合木局把未土合走，官失根 → 名分被合去，**有名无实的十年** | 官星无根不是"对峙"，是"虚" |
| **2030 庚戌** | 本运唯一"全实"之年（因他年皆虚） | 本运**唯一三样俱全**之年：庚透制劫 + 第三财库 + 卯戌合火 | 结论不变，理由由"别处虚"改为"此处实" |
| **癸酉运 13–22** | 酉空 + 冲卯 → 挫折 | **酉冲卯（冲羊刃）+ 正官有力**：强约束、强转折；癸水正印透干主学得进 | 挫折的成因是冲，不是空；**校准钩子保留，机制改写** |

**这类错误为什么难自查**：空亡版读起来同样自洽，语气甚至更"专业"；偏差又集中在应期上，而应期最容易被事后找补。所以不能靠"读着顺"来判，只能靠**去空亡检验**——删掉所有空亡句，若结论倒掉，就是越界。

**沉淀成两条规矩**（已写入 `maisui.md` 一·空亡定位 与 SKILL.md「取断依据纪律」）：
1. 空亡只作修饰语，不作主语；只减力，不翻转。
2. 任何仅由神煞支撑的结论，一律重述为结构性依据。

## 四、案例库扩充方式

微信不开放公众号历史文章列表，无法批量抓取。可行路径：

1. **手工喂链接**：给 `mp.weixin.qq.com/s/xxx` 链接 → 抓正文 → 按本文件格式追加一行。
2. **用户口述实盘**：用户提供的真实八字 + 真实经历，是**最高价值**的素材（因为它带反馈）。每收一个，就在本文件"本机案例"节下追加，并注明哪些结论被印证、哪些被推翻。
3. **优先收集方向**：目前样本偏"婚姻/债务"类，缺"事业上升型"（清而厚、药透）的正例。补到 3–5 个正例后，评级标准才算双向校准过。

**收录纪律**：
- 只收有反馈的案例；无反馈的只有断语，校准价值低。
- 断错必须记录（如 136），删掉错例等于自欺。
- 反馈要与断语逐项对齐，不做"大致对了"的模糊处理。
