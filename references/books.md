## 一、《子平真诠》（清·沈孝瞻）—— 格局派根本经典

**核心命题**：八字入手，先观月令。月令为提纲，取格、取用皆本于此。

### 1. 取格总则（月令为提纲）
- 八字用神，专求月令。以日干配月令地支，察其透干与否。
- 月支本气透于天干 → 取为本气格（八格之一）。
- 本气未透，而中气、余气透干 → 取透出者为格。
- 若本、中、余气俱不透，或透而无力 → 以月支本气取格（暗格/杂气格）。
- 月支藏干透出多者，取力量最大、或位置最显（月干、年干）者为格。

### 2. 八正格（正格）
| 月支本气 | 十神 | 格局 | 成格要点 |
|---------|------|------|---------|
| 寅申巳亥 中 | 正官/七杀 | 正官格/七杀格 | 官宜透、宜纯、宜有财印相随 |
| 子午卯酉 中 | 正印/偏印/食神/伤官 | 印格/食伤格 | 印宜官杀生，食伤宜财泄或配印 |
| 辰戌丑未 中 | 正财/偏财/正印/偏印 | 财格/印格 | 财宜食伤生、官杀护；印宜官杀生 |

### 3. 用神 / 相神 / 喜神 / 忌神 / 仇神
- **用神**：月令所取、成格之十神（格局核心）。
- **相神**：辅佐用神、使格局成者（如正官格之财、印）。
- **喜神**：生扶用神、相神者。
- **忌神**：损伤用神、相神者（破格）。
- **仇神**：生忌神者。
- 格局之"成"：用神得力、相神有情、无忌神破。"败"：用神受损、相神无力、忌神猖狂。
- 救应：忌神出现而有他字制化 → 败中有成（如官逢伤，有财化伤生官，或印护官）。

### 4. 八格成败举例（沈孝瞻原旨）
- 正官格：官逢财印 → 成；官逢伤官无制 → 败；官煞混杂 → 败（去留方成）。
- 财格：财旺生官、财逢食生 → 成；财党煞、财被劫 → 败。
- 印格：印逢官杀 → 成；印逢财坏 → 败（财印交战需位置/合化解）。
- 食神格：食神生财 → 成；食神制煞（专用）或配印 → 成；食神见偏印（枭神夺食）→ 败。
- 伤官格：伤官生财 → 成；伤官佩印（身弱）或伤官驾煞 → 成；伤官见官无制 → 败（"伤官见官，为祸百端"，须有财通关或印制）。

## 二、《命运的求索》（李涵辰《八字预测学》体系）—— 新派代表

**核心命题**：以"日干旺衰"为第一切入点，建立可操作的预测体系；强调
"百神论""空亡""体系化断语"。

### 1. 日干旺衰定量（新派）
- 以月令（月支）为旺衰基点，看日干在月令的旺相休囚死。
- 得令 + 得地（地支有根）+ 得势（天干有比劫印）三者综合定身旺/身弱。
- 新派强调"日干对命局中每个字"的扶抑，量化打分，与旺衰派传统一致。

### 2. 百神论（借神）
- 命局中某十神缺失时，用"同性干"替代该十神以定六亲/事象（如父以偏财看，
  局中无偏财则借正财或他干代）。用于六亲定位与事象取象。

### 3. 空亡用法
- 旬空之字，在断事中应期与力量上"空"——出空、填空、冲空方实。
- 用神落空亡 → 力量打折，须待冲合填空之年发动。

### 4. 体系化断语
- 新派重"断语＋条件"，如"身旺官杀为用，官杀透干有职位"等，强调条件匹配，
  反对单象直断。

> 提示：新派（李涵辰）与古法在细节（如空亡、百神）上有发明，本技能取其
> "旺衰定量 + 条件断语"的严谨性，但不盲从某一派绝对结论。

## 三、《滴天髓》（宋·京图 述，清·任铁樵 注）—— 理气根本

- "天道有寒暖，地道有燥湿" → 调候思想源头。
- "能知旺衰之真机，方识进退之奥妙" → 旺衰须看全局生克，非仅月令。
- 用神："用神不可损伤，日主最宜健旺"——扶抑用神原则。
- 六亲："夫妻姻缘宿世来，喜神有意"——十神配六亲。
- 强调"清"与"浊"：格局清纯则贵，浊混则贱（与子平真诠呼应）。

## 四、《渊海子平》（宋·徐大升）—— 基础歌赋

- **四言独步**："先天何处，后天何处，要知来处，便是去处"；"官星正气，忌见刑冲"。
- **五言独步**："有病方为贵，无伤不是奇；格中如去病，财禄两相随" → 病药说雏形。
- **二八定律/羊刃**："羊刃冲合岁君，勃然祸至"。
- 十神基础定义、六亲定位（正偏财为父妻、正偏印为母、官杀为夫/官、比劫为兄弟）。

## 五、《穷通宝鉴》（栏江网）—— 调候用神专书

按月令五行调候取用（寒暖燥湿）：
- 正月（寅）木：初春犹寒，丙火（太阳）调候为先，癸水（雨露）润之。
- 夏令（巳午未）：火炎土燥，急用壬水、癸水，次取庚金发源。
- 冬令（亥子丑）：金寒水冷，急用丙火暖局，戊土止水。
- 秋令（申酉戌）：金旺木凋，用壬水泄秀、丁火炼金（庚金喜丁）。
- 总纲："寒虽甚，要暖有气；暖虽至，要寒有根。"

## 七、各派别要点对照

| 派别 | 入手点 | 核心概念 | 擅长 |

| 旺衰派（含新派） | 日主强弱 | 得令/得地/得势、扶抑用神、调候、病药 | 用神喜忌、补泄 |
