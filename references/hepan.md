# 合婚方法论（hepan · 五维框架）

本篇为八字合婚（两人命局对照）的方法论补充，与 `bazi_method.md` 的旺衰/格局派单盘框架配合使用。
合婚核心：**看两人命局能否互补共生、气场能否相融相守**。须五维综合判断，不可单凭一点定吉凶。

---

## 一、年柱纳音适配
- **上等**：男命年柱纳音五行**克**女命年柱纳音（正克有度，主男方掌控护家），或**女命纳音生男命纳音**（女助男）。
- **中等**：男女双方年柱纳音**比合**（同类）。感情尚好、遇事可协商。
- **下等**：女命纳音**克**男命纳音（女压男，气场压制、男压抑）。
- 注：「克」非必凶；男克女为责任护佑之象，常优于女克男。

## 二、喜用神互补（最核心）
- **上等**：一方喜用神恰为对方命局旺气/优势五行；一方忌神恰被对方五行克制化解 → 双向滋养、彼此成就、互相旺运。
- **下等**：双方互为忌神，气场抵触、互相拖累、情绪内耗。
- 判读要点：列出双方「喜用 / 忌神」，交叉看「对方能否补我所需、化我所忌」。

## 三、干支多合少冲
合多冲少为吉，冲多合少为凶；直接对应相处状态与矛盾多少。
- **天干五合（情合）**：甲己、乙庚、丙辛、丁壬、戊癸。男女**日干相合**主缘分深、沟通畅、懂包容；年/月干相合主原生家庭与同辈人脉相融、阻力小。
- **地支六合/三合（缘合）**：子丑、寅亥、卯戌等六合；申子辰、亥卯未等三合。主步调一致、默契高、矛盾易解。**日柱鸳鸯合（日干合+日支合）**为顶级组合。
- **刑冲害（矛盾根源）**：六冲、六害、三刑多则性格对立、争吵多。**日支相冲/相刑/相害危害最大**（夫妻宫受损）。六害（子未、丑午、寅巳、卯辰、申亥、酉戌）力度轻于六冲，但**日支相害主"同处一室而处处不顺手"**——不断裂，却常年摩擦，比冲更难察觉。
- **天合地害 / 天合地冲**：日干相合而日支相害（或相冲）。**这是最需要单独认的一类**：天干合主"分不开"，地支冲害主"过不顺"。表现为感情黏性强、现实摩擦多，吵完了又离不开。**不可因日支冲害就断"不成"或"必离"**——天合在前，牵连力大于地支之害。
- 天干五合不分柱（任何位置的甲遇己皆论合），合婚跨盘任何甲己/乙庚等皆算。

## 四、夫妻宫安稳
日支为夫妻宫（婚房根基），合婚必参：
- **上等**：双方夫妻宫皆安稳无破、无自刑、无冲害；坐喜用神者婚恋福气足；双方夫妻宫互相生合者彼此珍视。
- **下等**：夫妻宫逢冲/自刑/坐忌神，婚恋心性不稳、猜忌重、易矛盾。
- 夫妻宫五行相生（如戌土生子水）亦为吉象。

## 五、格局呼应、五行平衡（加持项）
- **阴阳互补**：一阴一阳刚柔相济为上；双阳/双阴则缺调和，需互让（但可被天干合化解）。
- **运势同步**：两人大运起伏节奏相近、发展同步为上；一方猛进一方停滞，认知鸿沟易致疏离。
- **无严重凶煞互见**：孤辰、寡宿、红艳、烂桃花等凶煞互不叠加，外缘干净、少干扰。

## 六、综合判读（评级表）
| 维度 | 上等信号 | 下等信号 |
|------|----------|----------|
| 年柱纳音 | 男克女 / 女生男 | 女克男 |
| 喜用互补 | 互为喜用、忌神互化 | 互为忌神 |
| 干支合冲 | 多合少冲、日柱鸳鸯合 | 多冲刑害、日支相冲 |
| 夫妻宫 | 安稳无破、互相生合 | 逢冲/自刑/坐忌 |
| 格局呼应 | 阴阳互补、运势同步、无凶煞互见 | 双忌神叠煞、运势背离 |

**结论纪律**：五维中「喜用互补、干支合冲、夫妻宫安稳」为三大核心，俱上等即奠定良缘基调；纳音/阴阳为次要调节项。综合评定等级（上等 / 中等 / 下等），并标注各维强弱，不铁口断「必成/必离」。

## 七、两层分离：能否成婚 ≠ 相处质量

这是合婚最容易混淆的一处，必须分开判。**五维评的是"婚后过得怎样"，不是"能不能成"。**

| 层 | 判什么 | 依据 | 出错后果 |
|---|---|---|---|
| **第一层 · 成婚** | 两人是否构成配偶关系 | 配偶星与日主的**双向指向**（见下） | 把"不合"误判成"不成" |
| **第二层 · 质量** | 婚后是滋养还是消耗 | 上面五维 | 把"能成"误判成"过得好" |

**配偶星双向指向**（成婚的硬信号，比五维更硬）：

1. **男命财星 = 女方日主**，或**女命官星 = 男方日主**。单边出现即强指向。
2. **双向都成立**时，为最强组合：他的妻星正是她，她的夫星正是他。此类婚姻几乎不受五维高低影响——五维再差也挡不住，五维再好也无需它来促。
3. **一方配偶星原局全无，而另一方日主恰为该星** → 判作**配偶星外求**，不是"婚缘薄"。只在与该日主之人结合时成立，遇到别的日主则依然无星。

> 由此得一条硬纪律：**五维评级低 ≠ 婚姻不成立。** 五维低只说明"过起来费劲"。把五维当准入条件，是最常见的误判。

## 八、婚期应期：运层窗口法

单盘断婚期只能给**候选集**，不能给唯一解。原因很硬：一个人的婚期是两个人共同决定的，单盘看到"某年财星大动"，对方那年可能正在"妻宫伏吟"（主不动）。

### 8.1 第一步永远是运层，不是流年

**先算两运重叠，再谈流年。** 婚姻宫被引动，大运层面是"持续状态"，流年层面只是"触发"。窗口由运定，年份由流年筛。

1. 排两人大运，各自标出**哪些步运在引动婚姻宫**（日支被冲、合、害、三合半合，或运支为配偶星）。
2. **取两运重叠的区间**，这就是婚期窗口。窗口通常十年左右。
3. 流年**只在窗口内**筛，窗口之外的一律不看——除非有极端信号（如流年与日支成三合）。

> 只看流年、不看运行不行？不行。流年每年只给两字，信号又短又杂；运给十年定调。"哪十年能成"比"哪一年最像"可靠得多。

### 8.2 运已动宫，流年免动宫

这是最容易做过头的一步。**若大运本身已在动婚姻宫（如运支与日支六合/相冲），则流年不必再动一次宫，只需不破坏。**

此时流年的任务是**过否决项**，不是再找动象：

| 否决项 | 说明 |
|---|---|
| **婚姻宫伏吟** | 流年支 = 本命日支。主"原地重复"，与"新立门户"相抵。**一票否决** |
| **日主被冲** | 流年冲克日干之根，主自身动荡，难定 |
| **新起大冲** | 流年与日支构成三合/三会而化忌，或冲开配偶星 |

**加分项**（不是必要条件）：

| 加分项 | 说明 |
|---|---|
| 流年婚姻宫再被合/冲 | 双动，信号最重 |
| **大运交运之年**（前后一年内） | 整步运性质切换，人生结构随之变动，**应期高发点**（此条最常被漏） |
| 配偶星透干 / 得地 / 入库 / 被合 | 见 8.4 |
| 配偶星与日主相合 | 如乙庚合 |

### 8.3 排序：最早合格者优先，不取最漂亮者

**这是本框架最容易犯的错，且犯了很难自查。**

按强度排序会得出"信号最重的那一年"，但事实往往落在**更早、信号较弱、但已合格**的一年。原因不在命理，在现实：**人一旦条件具备就结婚，不会等到信号最漂亮的那一年。**

正确排序：

1. 窗口内**最早**通过否决项的年份 → 主选。
2. 其后通过者 → 备选，按"距主选年数"给出次第。
3. **只有窗口内仅一年通过否决时**，才可下唯一解。

**强度只用来解释"为什么是这一年而不是别的"，不用来排序。** 把强度当概率，是这个框架最隐蔽的错误——因为它在纸面上永远自洽。

### 8.4 配偶星"到位"的四种形态（透干非必要）

男看财、女看官。到位有四态，**得一即可**，不必天干透出：

| 形态 | 例（男命，妻星乙木） | 强度 |
|---|---|---|
| **透干** | 流年天干见乙 | 最显，但**非必要** |
| **得地** | 流年地支为其禄/刃/长生（如卯为乙之禄） | 强，等同透干 |
| **入库** | 流年为其墓库（如未为木库） | 中，主"藏而待发" |
| **被合** | 流年与日支（妻宫）六合/三合/半合 | 强，且直接动宫 |

**硬纪律**：不得因"该年天干不见配偶星"就剔除一年。凡以"财透"为必要条件去筛年，会把大量真实婚期筛掉——尤其当窗口内天干全为官杀印比时（连续三四年无财透是常见情形）。

### 8.5 筛年流程（按序，不可跳）

```
① 定运层窗口（两运重叠，且都动婚姻宫）
② 窗口内逐年过否决项（伏吟 / 日主被冲 / 新起大冲）
③ 通过者按"最早优先"排序，给主选 + 备选
④ 强度与加分项用于解释，不用于排序
⑤ 仅当通过者只有一年，才下唯一解
```

**常见错法**（两条均为本框架建立时亲历，代价是一次比一次大）：
- 只看一人的盘定唯一解 → 两人各得一个年份，差了好几年，而事实是同一桩婚姻。两个"唯一解"互斥，就是方法错了的警报。
- 把"官杀只在某步大运出现"当成"婚期必须落在该运内" → 这是把用神出现当成了婚期窗口。夫星不现之人，流年遇官杀同样成婚；用神运只是"更顺"，不是"唯一许可"。
- 把卯酉冲（冲夫妻宫）一律读作"散" → 冲也主"动而成家"。冲的吉凶要看**同时有无合来承接**。
- **筛年时以"配偶星透干"为必要条件** → 会把连续数年无透干的真实婚期整段排除，然后在远处挑一个"信号最重"的年份，错得还很自信。

## 九、跨盘合冲的取舍顺序

同一对盘里，合与冲往往同时存在（如日干合、日支害、月支冲）。不可简单数"合几个、冲几个"相抵，按以下优先级：

1. **日柱之间**（日干合 / 日支合冲害）权重最高——这是夫妻本体。
2. **月支之间**次之——成长环境与价值观，主"日常能不能过到一块"。
3. **年支之间**再次——原生家庭与门第，主"两家人合不合"。
4. 时支主子女与晚年，权重最低。

同层级内：**合 > 冲 > 刑 > 害**，但天干之合的**连接强度**高于地支一切冲害。故"天合地害"仍属可成之配，只是相处辛苦。

## 十、亲子盘对照（三方校验）

有子女的八字时，多出一个独立的检验面。**用途是校验，不是主断。**

### 10.1 三个用法

| 用法 | 做法 |
|---|---|
| **校验** | 父母盘的应期（婚期、生育）能否与子女盘对上。对得上，说明判法方向成立；对不上，先查数据再查判法 |
| **约束** | 缺任一方出生时间时，用其余两盘反推该方的关键节点，缩小范围 |
| **定位** | 子女的用神在父母盘里的强弱，决定"药"主要来自哪一侧——这是唯一能直接说给当事人听的部分 |

### 10.2 生育应期（与婚期同构）

- **子女宫** = 时支。
- **子女星**：男命看官杀，女命看食伤。
- **成立条件**：双方子女宫**同时被引动**。宫动是主，星动是次。
- **星透不是必要条件**，得生即可（地支生子女星、或子女星本有根）。
- **否决项与婚期相同**：子女宫伏吟（该年成不了）、日主被冲。

宫被不同方式引动，性质不同：

| 宫的状态 | 象 | 常见情形 |
|---|---|---|
| **被合** | 聚、定 | 计划内、顺理成章。**成婚最正的一种动** |
| **被冲** | 动、变 | 意外得子、时间提前；冲开财库者，兼主财动 |
| **被刑** | 动而带耗 | 得子过程辛苦（孕期、身体消耗大）；成婚则过程周折 |
| **被害** | 动而有阻 | 有人动、有阻碍，且阻碍常来自不显眼处。**减分型动象**：宫确实动了，所以有事发生，但过程不顺 |

六害（子未、丑午、寅巳、卯辰、申亥、酉戌）在应期里的权重低于合冲刑，但**不能当作"宫未动"处理**——害也是动。遇到害年，正确写法是"该年有动象，但伴随阻碍"，不是"该年不成"，也不能写成合冲那样的正动。

一方合、一方刑/冲，是最常见的组合——**"一拉一推"，事就成了**，与婚期的结构同源。

### 10.3 亲子盘的三类硬呼应

**① 月柱呼应（父母宫）**

月柱为父母宫。若子女的月柱某字与父或母的日主**同字或同支**，指向该方对子女的影响更深。若同时该字又是十神中的某一类（如恰为劫财、正印），则这层关系的**性质**也一并确定。

**② 日支冲合（立场与本体）**

子女日支与父母任一方日支的关系：

- **相冲** → 立场、观念、做事方式容易对不上。但两支若同为土（辰戌、丑未），冲开则两库皆开，**各自缺的东西反而被撬出来**。判断要看"冲开的是什么"，不是"冲了"。
- **相同 / 相合** → 同气相求，亲近，但也容易在边界上混同。

**③ 用神分布（药的来源）**

把子女的用神逐项对照父母盘：在哪一方透干、有根、有力，那一侧就是实际支撑较多的一方。反之，若用神在某一方全无，该方的助力就有限——**这与亲疏无关，是结构差异**，讲的时候要分清。

### 10.4 四条纪律

1. **只作校验，不作主断。** 亲子盘对上只能说明判法方向成立，不能反过来用父母的盘去推子女的命。
2. **不做"谁克谁"的判断。** 十神里"克我"与"同我"是两种完全不同的关系：克我为官杀，同我为比劫。同气之人亲近是结构决定的，不是害。凡落到"某方克某方"的说法，一律改写为"同气/异气 + 边界问题"。
3. **藏 ≠ 晚。** 单条结构（妻星藏妻宫、夫星入库等）只能说明"姻缘不显于外、要靠运引"，**不能直接推出时间早晚**。同一结构在不同盘上，早婚晚婚都出现过。
4. **隐私红线。** 父母与子女均为真人时，三盘信息一律不进公开案例库，只留本地。要沉淀规则，就写抽象形态。

### 10.5 校验失败时，先查三件事

若父母盘的应期与子女盘竟然完全对不上（如生育年双方子女宫皆静），按顺序排查：

1. **时柱是否校正过**——子女宫在时支，时柱错则父子两条线全错。
2. **真太阳时是否落入前一日**——日柱错则日支（自身与配偶宫）全错。
3. **年份是否农历**——报农历年导致整条流年序列偏移一年。

三条都排除了才怀疑判法。**数据错比方法错的概率高得多。**
