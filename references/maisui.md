## 一、这套断法的定位

它是**结构断法**，不是象法。

术语全部取自《滴天髓》《子平真诠》（格局、用神、相神、病药、调候），但落脚点始终压在一条线上：

```
旺衰 → 病 → 用神 → 大运 → 应期
```

它**不用**盲派那一套取象直断（不看"门朝哪边""祖坟有树"），也**不靠神煞定吉凶**（羊刃、桃花、空亡只作辅助意象）。好处是：每条结论都能讲清"为什么"，因此**可以被验证、可以被事后校准**。这也是它能做成案例库的原因。

### 空亡与神煞的定位（最易踩的坑）

空亡是**旬空**，作用是"减力 / 延后"，不是"定性 / 翻转"。分界线只有一条：

| ✅ 允许 | ❌ 禁止 |
|---|---|
| 某运或某年"力有折扣" | 因空亡把**整步大运**判成"虚耗" |
| 应期"略延后" | 因空亡把某年**由吉改凶**（或由凶改吉） |
| 冲遇空称"空冲，雷声大雨点小" | 因空亡把应期**整体推后四五年** |
| 判词里写"带虚意""落不实" | 把空亡当作吉凶的**成因**来解释 |

**去空亡检验**：把结论里所有涉及空亡的句子删掉。若结论随之不成立 → **该结论作废**，改用冲、合、透干、旺衰、大运引动重述。

**空亡只能做结论的修饰语，不能做结论的主语。**

同一条纪律适用于天乙贵人、华盖、羊刃等一切神煞：**可以进判词，不能进断据。**"天乙贵人来调停""华盖主孤高"这类话只能作修饰，不能用来解释某一运为何吉或凶。


一句话概括风格：**断语像诊断书，不像算命话。** 有病因、有层次、有时间点。

## 二、六步流程（顺序不可跳）

### 第 1 步 · 定盘（先于一切）

**时柱错，全盘皆废。** 这一步没做完，后面推得越细，错得越远。

1. 先跑 `scripts/truesolar.py` 做真太阳时校正（经度差 + 均时差）。
2. 看"边界余量"：
   - **低风险**（≥45 分钟）→ 时柱确认，可推。
   - **中风险**（30–45）→ 推，但标注"若为某时则如何"。
   - **高风险 / 极高风险**（<30）→ **必须并列两版结论**，并明确告诉用户"哪一条依赖时柱、哪一条不依赖"。此时**非时柱的结论（日主旺衰、月令格局、年柱六亲）仍然有效**，先给这些，别硬猜。
3. 同时确认性别（大运顺逆全反，不是小差别）。

> 反推技巧：若用户只给四柱不给日期，用"年柱 + 月令节气区间 + 日柱 + 时柱干"交叉定位到具体日期，再反推起运岁数，与用户实际经历比对（如"你 2016 年是否换过环境"）来验盘。**验盘比排盘重要。**

### 第 2 步 · 定旺衰（定底）

按 `bazi_method.md` 第三阶段走：得令、得地、得势，得出日主层级。

**但要多做一件事：分清"旺在哪"。** 身旺可能是比劫旺、可能是印旺，两者的病完全不同：
- 比劫旺 → 病在**夺财、争妻**，出口在官杀（制）和食伤（泄）。
- 印旺 → 病在**埋身、滞塞**，出口在财（破印）和食伤（耗印）。

只说"身旺"是没断完的，必须落到"旺在哪个十神"。

### 第 3 步 · 找病（最关键的一步）

**病不是"缺什么"，是"偏枯且无制"。**

找病的方法：把全盘最偏的那一处找出来，然后问三个问题：
1. 它有没有**制**？（克它的字在不在、透不透、有没有力）
2. 它有没有**泄**？（它生的字能不能把气导出去）
3. 它有没有**被引动**？（大运流年会不会来加旺它）

三问全是否 → 这就是病，且是重病。有一项是 → 是病但有救，看大运什么时候来救。

**病的常见形态**（可直接对照）：
| 病形 | 特征 | 典型后果 |
|---|---|---|
| 比劫夺财 | 比劫多且贴身克财，财无官护 | 钱守不住、被分利、争妻 |
| 财多身弱 | 财旺而日主无根 | 有财路无福享、因财致累 |
| 官杀混杂无制 | 官杀并见、日主无印化无食制 | 压力大、被动、多是非 |
| 伤官无制 | 伤官旺透、无印无财通关 | 才华外露但伤人伤己、婚不顺（女命尤甚） |
| 水大木漂 / 木多火塞 | 一方过旺把另一方架空 | 根基虚、做事无着力点 |
| 用神无根 | 用神透干但坐下无根、无源 | 有机会抓不住（见下"清而薄"） |

### 第 4 步 · 取用神（并给用神"评级"）

取用神守三条优先级：**调候 > 病药 > 扶抑**。冬夏生人先看寒暖，这一条常压过扶抑。

取到用神后，**必须做麦穗那套"三层评级"**（这是他最核心的判断工具，详见第三节·2）：

- **清而厚**：用神透干、有源、有护卫 → 上格，可断"能成事"。
- **清而薄**：格局干净，但用神藏支不透 / 无源 / 被克 → **降一层**，且必须提前标出"哪些流年会引动灾祸"。
- **浊**：用神不现，或现而被合被冲 → 常人之命，断"平稳中带波折"，不要硬拔高。

**评级决定语气。** 清而厚可以断"发"，清而薄只能断"有机会但守不住"，浊就老实说"普通"。麦穗之所以断语敢下又不失准，靠的就是这个分档——他的重话（310 的"志消神散"）都出在"清而薄"且用神被克的盘上。

### 第 5 步 · 判大运（先运后格）

**顺序是：先看大运走向，再回头定格局层次。** 这与一般"先定格再论运"相反，是麦穗的招牌。

理由：特殊格局（从格、化气格、从儿格、专旺格）**必须格局与大运同向**。原局再纯，大运一路逆行，就是"格越纯，摔得越重"。

所以流程是：
1. 排出大运序列（顺逆、起运岁，脚本已算）。
2. 看**第一步大运**的方向：是助格还是破格？→ 这一步定了人生前二十年的底色。
3. 找**最好的那一步**（用神到位、病被制化）和**最差的那一步**（忌神当值、格局被破）→ 这就是"转机"和"难关"的时间点。
4. 回头定格局层次：**格局的价值取决于它能不能等到那步好运**。等得到 → 层次高；等不到或运太晚 → 降层。

> 麦穗的常见判词："命好不如运好"、"原局好但大运破格"、"此盘属于熬出来的命，不是少年得志的命"。

### 第 6 步 · 落六亲与应期

逐项断（模板见第五节），每一条都要落到**具体年份或具体大运**。没有时间点的断语等于没断——不可验证，也就无法校准。

## 三、六个可复用的判断工具（本手册精华）

### 1. 病药优先于格局

先找病、再找药，格局用来定"层次上限"，病药用来定"能不能兑现"。一个病重的盘，格局再漂亮也只是纸面富贵。

**判断口诀**：**药透则贵，药藏则平，药无则困。**
- 药透干且有力 → 病去，是"去病得贵"，可断上格。
- 药藏支 → 有能力但发得晚，需运来引出。
- 药被克或被合 → 有救但救不彻底，断"反复"。

### 2. 用神"清而薄"三层评级

| 层级 | 判据 | 断语语气 | 必须补充的内容 |
|---|---|---|---|
| **清而厚** | 用神透干 + 有源（生它者有力）+ 有护卫（克它者被制） | 可断"能成事、有层次" | 何时最旺（大运流年） |
| **清而薄** | 格局干净，但用神**藏而不透 / 无源 / 被克**（满足任一即算） | 降一层，断"有机会但守不住" | **必须标出引动灾祸的流年** |
| **浊** | 用神不现；或现而被合、被冲、被隔 | 断"平稳带波折"，不拔高 | 忌神当值的年份 |

**"薄"的四种成因**（对照检查）：
1. 藏支不透——有能力使不出。
2. 坐下无根——用神自己站不住。
3. 无源——生它者也被克（如"午火无源"）。
4. 被贴身克——最要命的一种，如用神旁紧贴一个克它的字。

> 例：310 的午火（伤官配印，印星无源无护卫）、255 的丙火（日主弱不受生）、320 的己土（君赖臣生但己土卑湿）。三例都因此降层。

### 3. 财分两笔（正财 / 偏财，性质完全不同）

这是最"实用"的一条，几乎每个盘都能用：

| | 正财 | 偏财 |
|---|---|---|
| 性质 | 工资、固定收入 | 资产、投资、意外财 |
| 位置 | 常透干 | 常藏支、坐库 |
| 脆性 | **脆**，比劫贴身就夺 | **韧**，入库则锁得住 |
| 断语 | "工资到手就散" | "置产反而留得住" |

**推论（这是能直接给建议的地方）**：若一个盘"正财被劫、偏财入库"，那么——
- **涨薪对他处境的改善，远小于把涨的钱变成不可动用的资产。**
- 存钱方式必须改成"到账即锁定"（定期、定投、不动产），不能靠自制力。
- 忌"可支配现金 + 讲义气 + 有人开口"这三样凑齐。

### 4. 比劫夺财的三种形态（分开断，不能混）

很多人一看"比劫多"就说"破财"，太粗。要分形态：

| 形态 | 结构 | 现实对应 |
|---|---|---|
| **贴身劫** | 比劫与财星紧贴（相邻干支） | 钱被身边人直接分走；合伙吃亏；兄弟朋友借贷 |
| **合被隔断** | 日主与财本可合，中间横一个比劫 | "差一步"：谈得好、到关键节点定不下来；感情易被截断 |
| **财坐受克** | 财星坐下的地支克它 | 财本身立不住：赚得快、漏得也快；家底虚 |

三种同时出现 → "财在门户而守不住"，可断"能挣但存不下"，并给"改存钱方式"的建议。

### 5. 用神一物多用 / 一神多伤（清单法）

一个用神往往同时干几件事（如丁火：暖局 + 泄旺 + 生财）。**要把它的每一项功能单独列出来，逐项检查有没有被破坏。**

```
丁火的三项功能：
① 调候暖局  → 亥月水寒，是否被亥水克？ 是 → 这一项打折
② 泄木旺气  → 是否被戊土晦？ 是 → 这一项打折
③ 生戌土财  → 是否火土相生成立？ 成立 → 这一项有效
```

三项全打折 → 用神虽在，等于没有。这比笼统说一句"用神是丁火"有用得多，也是"清而薄"评级的具体来源。

### 6. 断语必须带"反馈位"

麦穗的写作范式值得学：每条断语后面留一个"反馈"位。**这不是格式问题，是方法论问题**——它逼你把断语说得足够具体，具体到可以被证伪。

不可验证的断语（"你命中有贵人""中年有变动"）写一百条也提高不了水平。可验证的断语（"至迟丙午年必离""唯己未运 2027 丁未年有婚期"）写一条就够校准一次。

## 四、六亲逐项断法

按麦穗的固定顺序走，不要跳项。每项先看**星**（十神）再看**宫**（柱位），星宫同断。

### 父母
- **父**：偏财。偏财被劫、坐绝、入墓 → 父辈"挣得到守不住"或缘分薄。
- **母**：正印。印被财坏（财旺克印）→ 母亲操劳或健康有损。
- 年柱为祖上、月柱为父母宫。年柱被冲 → 早年环境动荡、离乡。
- 断法示例：年干财被月干比劫贴身克 → "父辈的钱也是挣得到守不住那一类"。

### 兄弟
- 比肩为兄姐、劫财为弟妹（阳男阴女顺排时的对应，实务上统看比劫）。
- 比劫数量 + 是否得地 → 兄弟姐妹几个、有无助力。
- 比劫为忌且旺 → 兄弟不助反累；为喜且旺 → 有靠。
- 特殊：比劫全无根 → 独生或同胞缘薄。

### 学历
- **印**主吸收（能不能学进去）；**食伤**主输出（能不能考出来）；**官**主名分（学历能不能兑现）。
- 三者只看一：印旺食伤弱 → 学得进但考不出；食伤旺印弱 → 聪明但坐不住。
- 学历层级看用神层级：用神清而厚 + 印有护卫 → 高学历；用神清而薄 → 学历中断或"读了没用上"。
- 常见断语："大专退学"（102）、"医院合同工考编三连败"（319）——后者是方法论典型：**带正官正印不等于必发贵**，官印被破照样考不上。

### 财运
**必须先分正财偏财**（见三·3），再谈多少。
- 财透干被劫 → 明财易失。
- 财藏库（辰戌丑未）→ 有储蓄能力，但需冲开才动（冲库年 = 大进大出年）。
- 财多身弱 → 财是负担不是福；财少身旺 → 需食伤生财，靠"做出来"。
- 断语要落到"钱以什么形态存在"，而不是"有钱没钱"。

### 婚姻（男女分开，方法不同）
- **男命看财**（正财为妻）。财被劫 → 争妻、易有第三方；财坐受克 → 妻缘薄；财入库 → 妻务实能持家。
- **女命看官**（正官为夫）。官星藏而不透 → 感情偏晚；伤官无制 → 克夫、婚不顺（须印制伤方成婚）；官杀混杂 → 多角关系、选择困难。
- **宫**看日支：日支被冲 → 婚姻动荡；被合 → 有外力介入；日支坐忌神 → 配偶带来负担。
- **星宫同断**：星好宫坏 → 人对但过不好；宫好星坏 → 条件好但人不来。
- **定婚期**：男看财星到位之年（财透、财合日主）、女看官星到位之年；再看大运是否助。麦穗惯例是给"唯某运某年有婚期"这种唯一解，而不是列举一堆年份。

### 子女
- 男命看官杀（或时柱），女命看食伤。
- 时柱为子女宫：时柱被冲 → 子女缘薄或晚得；时柱坐财 → 子女有经济能力。
- 时柱也是晚年运的宫位，时柱受损 → 晚景需留意。

### 事业（三条路径选一，不要三条都说）
| 路径 | 星 | 适合的盘 |
|---|---|---|
| **官杀路** | 官杀 | 官杀有力有制、日主能担 → 进组织、走科层 |
| **食伤路** | 食伤 | 身旺需泄、食伤有财承接 → 靠作品、技术、产出 |
| **印路** | 印 | 印有护卫、官印相生 → 靠资历、专业资格 |

**判断纪律**：一个盘只主推一条路径，另外两条说明"为什么不选"。若官星藏而不透，就明确说"靠熬资历在纯科层里往上爬，阻力大于走专业路线"，而不是笼统"事业有成"。

## 五、输出模板（麦穗格式）

按此结构写，可读性和可验证性都最好：

```markdown
## 定盘
四柱 + 日主 + 真太阳时校正值（含经度差、均时差）+ 边界余量与风险等级

## 原局
1. 旺衰：身强/身弱，且"旺在哪"（比劫旺 / 印旺）
2. 病：______（一句话点明，附三问检验）
3. 用神：______，评级【清而厚 / 清而薄 / 浊】，依据逐条列
4. 一句话概括（例："木旺成林，土薄被伐 —— 不是没有财，是财守不住"）

## 大运
当前大运 + 最好的一步 + 最差的一步（含年份区间与理由）

## 流年节奏
| 年份 | 干支 | 判断 | 该做/不该做 |

## 六亲逐项
父母 / 兄弟 / 学历 / 财运 / 婚姻 / 子女 / 事业

## 三条对治
1. 以___制___
2. 以___泄___
3. 财要___（落到可执行的动作）

## 定盘判词
一段文言化的总断 + 一段白话翻译

## 待确认
列出所有能推翻结论的变量（时柱、性别、出生地），说明各自影响哪些结论
```

**语气纪律**：
- 用"易 / 倾向于 / 利于 / 需注意 / 待冲实"，不用"必定 / 一定会 / 死 / 发"。
- 但**层次判断要敢下**："降一层""这个盘属于熬出来的命"——这是结构判断，不是宿命预言，可以明确。
- 每条断语后标注依据（哪个十神、哪个合冲、哪步大运）。

## 六、择时（宝宝选时辰）的判断逻辑

麦穗择时系列的范式，可以复用为"给定日期，选时辰"的标准流程：

1. **定月令**：先确定该日的月柱（节气交接日要特别注意，月令可能在当天切换）。
2. **逐时辰排**：把当天 12 个时辰各排一盘（男女各排一套）。
3. **每个时辰都要排大运**——这是关键。**只看原局好就选，是择时最大的坑**（第 50 期标题就叫"仅考虑原局好选，结合大运难选"）。
4. **淘汰规则**（按优先级）：
   - 特殊格局（从格/化气/从儿/专旺）与大运方向相悖 → **优先淘汰**，理由："格越纯，摔得越重"。
   - 用神被大运一路克伐 → 淘汰。
   - 男命劫财见财（克妻）、女命伤官无制 → 降级。
5. **排序输出**：不要只给一个"最佳时辰"，给 ✓ 排序（如"己卯 > 戊寅"）+ ✕ 淘汰清单并说明理由。
6. **加"说人话"层**：每个时辰配一段白话翻译，讲这个时辰的孩子大概什么性格、什么处境。

**三条铁律**（麦穗反复强调）：
- 黄历吉时是给所有人的，选时辰要看**八字 + 大运是否合**。
- 同一八字**男顺女逆**，大运完全不同，必须分性别论断（第 53、54 期男宝女宝结论完全相反）。
- 时辰要按**出生地真太阳时**换算，不能直接套北京时间。

## 七、常见误判与纠偏（对照自查）

| 误判 | 为什么错 | 正确做法 |
|---|---|---|
| 缺什么补什么 | 五行数量少 ≠ 喜用。身强忌印而印少，印少不是喜 | 看日主**需不需要**，不看**有没有** |
| 见正官正印就断贵 | 319 全篇主题：官印被破、被合、无根，照样考编三连败 | 官印要看是否**有根、有护、不被合冲** |
| 只看原局不看大运 | 原局好而大运破格，是最常见的"高开低走" | **先看大运，再定格局层次** |
| 见羊刃/桃花就断凶吉 | 神煞是意象不是主断 | 神煞只作辅助修饰，不单独下结论 |
| 男命女命同一套断法 | 大运顺逆相反，婚姻星完全不同 | 必须先问性别，分开推两版 |
| 直接用北京时间排盘 | 经度差 + 均时差可达 ±30 分钟以上，足以换时辰 | 先跑 `truesolar.py` 校正 |
| 时辰在边界上还硬断 | 错一个时辰，全盘结论作废 | 边界 <30 分钟必须并列两版 |
| 断语不带时间点 | 不可验证 = 不可校准 = 白断 | 每条都落到年份或大运 |
| **用空亡压低/抬高整步大运** | 空亡是旬空，只减力不定性；此派断运只看旺衰、冲合、透干 | 空亡只作"打折/延后"的修饰语，**不得作断运主据** |
| **用神煞解释吉凶成因** | "天乙来调停""华盖主孤高"是判词，不是断据 | 吉凶落到十神与冲合，神煞只进判词 |
| **应期只写"宜晚婚""中年后"** | 不可验证 = 不可校准 | 男看财星到位、女看官星到位，取唯一解年份 |
| 只断"好/不好" | 无法指导行动 | 断"哪几年该动、哪几年该守"，并给可执行动作 |

## 九、诚实边界

- 本手册归纳的是一套**内部自洽、可事后校验**的传统推演体系，不是命运预测。它的检验方式是"事后对照"，不是"事前证伪"。
- 同一个盘换流派（盲派、新派、台湾体系）结论可能差异很大。本手册只代表"麦穗这一派"的做法，不宣称是唯一正解。
- 涉及健康、婚姻、投资、职业的重大决策，以现实情况与专业意见为准。术数结论最多提供一个"反观的节拍"，不能作为安排人生的依据。
- 不得用于宣扬迷信、承诺改运消灾，或对他人施加恐惧性暗示。
