## 二、按主题归类（学习时按这个顺序读）

### 主题 A：用神"清而薄"四连（C01 / C02 / C03 / C04）

这四个盘是同一类病的四种表现，**建议连着读，体会评级的一致性**：

| 案例 | "薄"的成因 | 具体表现 |
|---|---|---|
| C02 | **无源 + 无护卫** | 午火为印，但生它者被克、护它者不见 |
| C03 | **日主担不起** | 丙火为用，但日主弱不受生 |
| C04 | **药本身质量差** | 己土为用，但己土卑湿，制水力弱 |
| C01 | **官印无根** | 有官有印，但都站不住 |

**共性结论**：这四盘都不是"没有用神"，而是"用神在，但兑现不了"。这类盘的结论都往下压一层，且都**提前标出会引动灾祸的流年**。

**复用写法**：
> "用神是 ___，但 ___（薄因）。所以不是没有机会，是机会来了守不住。降一层论。需要特别留意 ___ 年（忌神当值/用神被冲），那一年 ___。"

### 主题 B：先运后格（T01 / T02 / T03 / T04）

四个择时案例共同演示了一个反直觉的习惯：**原局漂亮但大运逆行 → 直接淘汰，理由不是"不好"，是"格越纯摔得越重"**。

- T01：丙辰、丁巳、戊午三个时辰原局成从强格，但大运一路水木 → 排除。
- T02：该篇的核心立场就是"只挑原局容易，配上大运难"。
- T03/T04：同一日同时辰池，男命女宝结论相反 → 性别决定大运方向，方向决定吉凶。

**复用写法**：
> "这个盘原局是 ___ 格，看起来很纯。但大运 ___。特殊格局要求格局与大运同向，现在方向相反——所以**不能按成格论**，要按 ___ 论。格越纯，摔得越重。"

### 主题 C：断语的时间点写法（C05 / C06 / C07）

三例都把时间**收得很紧**（一个年份或两年区间），而不是列举一堆年份：

- C05：晚婚，婚期收束到某运的某一年，只给一个点。**此例成立的前提**是"筛到底只剩这一颗"——该运内条件 A（配偶星到位）与条件 B（婚姻宫被引动）同时成立的只有那一年。不是"挑了个最好看的"。
- C06：断两年内必离，并给出最迟年限。
- C07：两年内婚变与负债，同样收在两年区间内。

**为什么敢这么收**：触发条件是**结构性的**——某星到位 + 某宫被冲/被合。但"结构上收得住"只是必要条件，**不等于事实会落在那一年**。

**必须配的警戒**：紧 ≠ 准。主题 D 的 C08 就是同一手的失败版——同样收成了一个点（"27 岁后"），实际是 20 岁早婚。所以：

- 收得紧，只能建立在**"窗口内其他年都已被否决项排除"**之上；
- 若窗口内还有几个合格年没排除，就不是唯一解，应给"主选（窗口内最早合格者）+ 备选"；
- **提前发生比推迟发生常见得多**——条件一旦具备，人就会动，不会等信号最漂亮那年。

**复用写法**：
> "在 ___ 运这十年里，条件 A 与条件 B 同时成立、且不逢伏吟的年份有 ___ 个。最早的是 ___ 年，若届时未成，则看 ___ 年。"

### 主题 D：断错了怎么复盘（C08）

C08 断"婚期应在戊午运 27 岁后"，实为 20 岁早婚、32 岁离。

**这是"择美不择实"的典型失败**：把"用神到位的运"当成了"婚期必须落在其中"，于是把 20 岁的早婚整个排除在候选之外。原文后来把它解为"早婚逆用神而动，故不稳，最终应验在正位"——这个解释在逻辑上自洽，但要警惕：**自洽的解释不等于判对了。**

判对是**事前**指出"20 岁这年宫被引动，会成婚"；"事后说早婚所以不稳"是另一种事后合理化，学不到东西。

**真正可学的两层**：

1. **婚期窗口只看"婚姻宫何时被引动"，不看"用神何时到位"。** 用神运决定这段婚姻的**质量**，不决定它**何时发生**。
2. **宫动而星未到 → 能成，但不长久。** C08 的"20 岁成、32 岁离"正是这个结构：宫被引动所以成了，配偶星尚未得力所以守不住。这一层是可以事前说的，只是当时没说。

**复用写法**：
> "这几年宫位被引动，会成；但配偶星尚未得力，成的这段守不住，真正的稳定期在 ___。"

**复盘纪律**：断错时先分清三种情况——
1. 结构判错（看错病/用神）→ 需修方法。
2. 结构对但应期错（时间点偏了）→ 方法可接受，精度待提。
3. 结构对但用户行为改变了轨迹 → 不算错，记录即可。

## 三、校准基线（三条）

本技能**不用私盘作基线**。以下三条取自公开案例，可直接拿来对照：

| 基线 | 案例 | 用途 | 对照动作 |
|---|---|---|---|
| **语气** | C02（戊土酉月，伤官配印，午火无源无护卫） | 学"清而薄"该下多重的话 | 你的断语比它轻 → 评级虚高，或病没找透 |
| **应期** | C05（庚金子月，伤官无制，女命） | 学"把时间收成一个点"的写法——但前提是先筛空窗口（见三·补二形态三） | 你的应期若是一串年份 → 视为未完成 |
| **复盘** | C08（壬水酉月，取午火为用，断 27 后必婚，实为 20 早婚 32 离） | 学断错怎么归类 | 先分"结构错 / 应期错 / 行为改变"三档 |

**用法**：断完新盘先定评级（清而厚 / 清而薄 / 浊），再找**同评级**的案例比语气。语气明显偏软或偏硬，多半是病找错了；应期写法对不上 C05 的颗粒度，就是没断完。

**为什么不放私盘**：真实私盘带反馈，校准价值最高，但涉及个人隐私，**不进公开仓库**。私盘只在本地留档；若要入库，必须脱敏改写为"构造示例"并明确标注。

## 三·补、空亡越界（规则反例）

这是本库最值得记的一条教训，用**抽象形态**写，不挂具体命例。

**越界形态**：某步大运的运支正好落在日柱空亡里，而这步运的运支又恰是**制病之药**（例如以七杀制比劫）。写的人很容易顺手判成"杀印双空、整运虚耗"，甚至据此把应期整体推后数年。

**错在哪**：运支带来的十神与冲合关系，不会因为落空而消失。七杀还是七杀，只是力打折；把"打折"读成"没有"，等于用一个装饰性概念推翻了结构性结论。

**正写三步**：

1. 先论运支之功：它是制劫、是生身、还是助病？这一步与空亡无关。
2. 再注修饰：加一句"力有折扣 / 应期略延"。
3. 最后查应期：回到财星（男）/官星（女）到位 + 宫位被冲合引动，取最实的一年——**这一步绝不能由空亡决定。**

**四条通用对照**：

| 越界写法 | 为什么错 | 正写 |
|---|---|---|
| 运支落空 → "整运虚耗、想动不得动" | 空亡只减力，不定性 | 先论运支十神之功（制劫/生身/助病），再注"力打折" |
| 流年支落空 → 由吉改凶或由凶改吉 | 定性不能靠空 | 吉凶看透干与冲合；空只影响"落不落得实" |
| 因空把应期推后数年 | 应期由星到位 + 宫被引动决定 | 给候选年份并排序，空亡不参与排序 |
| 用"某年全实 / 别处都虚"解释取舍 | 这是空亡的推论，不是结构 | 说"三样俱全"（透干 + 财库 + 合局），不说"别处虚" |

**这类错误为什么难自查**：空亡版读起来同样自洽，语气甚至更"专业"；偏差又集中在应期上，而应期最容易被事后找补。所以不能靠"读着顺"来判，只能靠**去空亡检验**——删掉所有空亡句，若结论倒掉，就是越界。

**两条规矩**（已写入 `liubu.md` 一·空亡定位 与 SKILL.md「取断依据纪律」）：

1. 空亡只作修饰语，不作主语；只减力，不翻转。
2. 任何仅由神煞支撑的结论，一律重述为结构性依据。

## 三·补二、单盘"唯一解"越界（婚期）

与空亡越界同类：都是把**不确定的东西说成确定**，但错法不同——空亡是拿装饰项当断据，这里是拿单盘当合婚。同样用抽象形态写，不挂命例。

### 形态一：一对夫妻，两个"唯一解"

**越界写法**：给一对确认为夫妻的两个人各断婚期，各自单盘各得一个"唯某年"的结论，年份相差好几年。

**错在哪**：婚期由**两个人共同决定**。单盘的"最强一年"只说明这人那年有动象，不说明对方也在动。两张单盘各说各话，合起来必然自相矛盾。

**关键机制——伏吟否决**：一方婚姻宫被合或冲（动象）的那一年，另一方可能正逢**流年支与本命日支相同**，即伏吟。伏吟主"原地重复、不动"。**此时无论动的一方信号多强，这一步都迈不出去。** 所以交集筛选里，伏吟是否决项，不是减分项。

**正写四步**：
1. 两盘各出候选（各 3–5 年），按强度分档，**不出唯一解**。
2. 取交集。无交集 → 判"原局层面婚缘不同步"，先质疑是否真为夫妻，不要硬凑。
3. 交集内排序：**一方合、一方冲 → 最强**（一拉一推）；双方皆合 → 次强（合则静，可成可缓）；双方皆冲 → 偏弱（动而不聚，主变动而非成家）。
4. 剔除任一方伏吟之年，即便另一人信号极强。

**两条警报**（出现即说明判法有问题）：
- 同一对夫妻，两次单盘各得一个"唯一解"，年份却不一致。
- 断婚期时用了"某星只在某步大运出现，所以必须在该运内成婚"——这是把**用神运当成了婚期许可**。配偶星不现之人，流年遇官杀同样成婚。

### 形态二：配偶星不见被判成"婚缘薄"

**越界写法**：某方配偶星在原局一位不见（男无财、女无官），判作"婚缘薄、必晚婚"。

**错在哪**：星不见有两解。一解是"姻缘弱"；另一解是**配偶星外求**——姻缘不在自己盘里，全由遇到的那个人带来。第二解须先排除，才能下第一解。

**判据**：查配偶的盘，**其日主是否恰为该星**。若是（男命妻星 = 女方日主，或女命夫星 = 男方日主），即为外求成立。此类组合单看自己永远断不出婚期，因为那个年份根本不由自己决定。

**双向成立时**（他的妻星正是她、她的夫星正是他）为最强指向，其强度压过五维的任何低分。

### 形态三：择美不择实（最隐蔽的一种）

**越界写法**：在若干个"都合格"的候选年里，挑出信号最重的那一年，定为婚期，并把"信号最重"说成"证据最硬"。

**错在哪**：这不是命理错误，是概率错误。**人一旦条件具备就结婚，不会等到信号最漂亮的那一年。** 把强度当概率，结论在纸面上永远自洽——因为最重的那一年确实"结构最完整"，只是事实没落在那里。

**更深一层**：一旦以强度排序，前面还会跟着一个更早的错误——**筛子收得太窄**。常见两种收法：
1. 要求配偶星必须**透干**。而"到位"本有四形态（透干/得地/入库/被合），得一即可。若婚期窗口内天干连续数年不见配偶星（很常见），整段窗口会被排除，人就被迫去远处挑一个"最好看"的年份。
2. 要求**流年必须再动一次婚姻宫**。而大运若已动宫（运支与日支六合/相冲），流年只需**不破坏**（不伏吟、不冲日主、不另起大冲），不必重复动宫。多加这一条，会把窗口内大部分合格年份筛掉。

**正写顺序**：

```
① 定运层窗口：两人大运同时在动婚姻宫的重叠十年
② 窗口内逐年过否决项（伏吟 / 日主被冲 / 新起大冲）
③ 通过者按「最早优先」排序 → 主选 + 备选
④ 强度与加分项只用于解释，不用于排序
⑤ 仅当仅一年通过，才下唯一解
```

**加分项里最常被漏的一条**：**交运之年**。整步运性质切换，人生结构随之变动，是应期高发点，尤其当交运前后恰是"冲妻宫 → 合妻宫"这类由动转定的切换。

**自查一句**：这个年份，是我从"最早合格"推出来的，还是从"信号最重"挑出来的？若是后者，重排一遍。

### 形态四：宫动判成星动（生育应期）

**越界写法**：断生育年时，以"子女星是否透干或被流年引动"作筛选条件。该年子女星不动，就判"非生育年"，转去远处找"星动之年"。

**实际结构**：生育年最常见的形态是**子女宫（时支）被引动**，而流年天干往往落在财星或印星上（添丁、得子之意），子女星本身并无动作。

**一方宫被合、另一方宫被刑/冲，是最常见的组合**——一拉一推，事就成了。双方宫皆静而仅子女星强动的情形，反而少见。

**错在哪**：与形态三同源。**筛子建在"星"上，而应期的主据是"宫"。** 宫动单独即可成立，星动只是加分。

**正写**：

```
① 取双方子女宫（时支）
② 逐年看该宫是否被合 / 冲 / 刑
③ 双方同时被引动 → 进入候选
④ 过否决项：宫伏吟（该年不成）、日主被冲
⑤ 子女星得生为加分项，透干非必要
```

**这一条与婚期其实是同一条规则**：宫动优先于星动。同一个错误会在婚期、生育两处各犯一次，因为两处的判据结构完全相同。

**自查一句**：我这个年份，是靠"宫被引动"选出来的，还是靠"星出现"选出来的？

### 由此确立的四条边界

1. **五维评的是"过起来累不累"，不是"能不能成"。** 已知有大量配偶星双向指向的组合，五维评分并不高却照样成婚。把五维当准入条件，是最常见的误判。
2. **单盘与合婚是两套流程**。单盘只出候选；一旦知道配偶是谁，必须走运层窗口法（见 `hepan.md` 第七、八节）。
3. **宫动优先于星动**。婚期、生育应期通用。凡以"星未到位"排除年份的筛法，都会漏掉真实年份。
4. **藏 ≠ 晚**。单条结构（妻星藏妻宫、夫星入库）只说明"姻缘不显于外、要靠运引"，不能直接推出时间早晚——同一结构在不同盘上，早婚晚婚都出现过。

## 四、案例库扩充方式

公开平台上没有可批量拉取的归档列表，只能逐篇取。可行路径：

1. **手工喂链接**：给单篇链接 → 取正文 → 按本文件格式追加一行（**只写归纳，不摘原句**）。
2. **用户口述实盘**：真实八字 + 真实经历带反馈，是最高价值的校准素材。但**只存本地，不进公开仓库**；确需入库，必须脱敏改写为"构造示例"（改日期、地点，并同步改四柱/大运/流年等可识别特征），且明确标注为构造。
3. **优先收集方向**：目前样本偏"婚姻/债务"类，缺"事业上升型"（清而厚、药透）的正例。补到 3–5 个正例后，评级标准才算双向校准过。

**收录纪律**：
- **隐私红线**：不得把真实出生信息（年月日时 + 出生地）写入公开仓库，也不得写入任何可能被认出的等价特征组合。
- **版权红线**：只记录结构特征、病位、评级、结论方向；**不摘录原句、不引用原标题、不搬原文段落**。凡须说明"某例说过什么"，一律改写成自己的表述，并保持信息量降到"结构 + 结论"这一层。
- 只收有反馈的案例；无反馈的只有断语，校准价值低。
- 断错必须记录（如 C08），删掉错例等于自欺。
- 反馈要与断语逐项对齐，不做"大致对了"的模糊处理。
- 示例优先用**已公开发布**的案例；无合适公开案例时，用明确标注的构造示例。
