# 八字解读方法论（bazi_method.md）

本文件是 AI 解读排盘的操作手册。排盘数据由 `scripts/bazi.py` 给出，
**AI 必须依据本手册与 `books.md` 做趋势化、条件化解读，不得铁口直断。**

排盘字段速查（见脚本 JSON 输出）：
- `pillars`：四柱干支；`day_master`：日主。
- `pillar_shishen`：四柱天干十神；`hidden_stems`：地支藏干及藏干十神。
- `wx_count`：五行数量（含藏干权重）；`strength_eval`：日主旺衰评分与得令/得地/得势/层级。
- `pattern`：格局派取格（月令本气初步）；`shensha`：神煞；`kongwang`：空亡。
- `dayun`：大运（顺逆、起运岁、序列）；`liunian`（可选）：流年十神。

---

## 第一阶段：问清信息（必做，先于排盘）

收到排盘请求后，先确认：
1. 公历出生年/月/日/时（注明是否已换算为真太阳时；未说明则按输入时间排，并提醒"时辰以出生地真太阳时为准"）。
2. 性别（大运顺逆依赖年干阴阳 + 性别）。
3. 想问什么（性格/事业/财运/婚姻/健康/学业/流年），决定解读侧重。
4. 提醒：23:00–23:59 按"晚子时"规则排（脚本默认开启，可用 `--no-night-zi` 关）。

---

## 第二阶段：跑脚本排盘（核心纪律）

**永远先排后解。** 调用（脚本与本 SKILL.md 同目录）：

```bash
python scripts/bazi.py -y 年 -m 月 -d 日 -H 时 -M 分 -s male|female
# 结构化输出（推荐给 AI 读取）：
python scripts/bazi.py -y 年 -m 月 -d 日 -H 时 -M 分 -s male --json
# 看近年流年十神：
python scripts/bazi.py -y 年 -m 月 -d 日 -H 时 -M 分 -s male --liunian 2026
```

> 路径说明：上述 `scripts/bazi.py` 相对本 SKILL.md 所在目录。若工作目录不在技能目录，
> 用绝对路径调用（如 `D:\dwh\Code\Python\ai_test\.opencode\skills\bazi\scripts\bazi.py`）。

脚本已精确处理：立春换年、节气换月、子时、地支藏干、十神、五行旺衰、大运起运与顺逆、神煞、纳音。
**不要用手推任何干支/大运，一切以脚本输出为准。**

---

## 第三阶段：旺衰派解读（日主强弱 → 用神喜忌）

依据 `strength_eval` 与 `wx_count`：

1. **三要素判定**（子平/新派共识，见 books.md 二、三）：
   - 得令：日主五行在月令为"旺/相" → 有根基。
   - 得地：日主五行在地支本气有根（禄/刃/库/长生）。
   - 得势：天干有比劫、印星帮扶。
   - 三者俱备 → 身强；三者皆无 → 身弱；居中 → 中和/偏强/偏弱（以脚本 `level` 为起点，但可结合藏干细判修正）。

2. **五行旺相休囚死**（月令定）：我（日主）同行为旺，我生为相，生我为休，克我为囚，我克为死。
   据此说明日主在月令的"气候"。

3. **用神喜忌（扶抑用神，books.md 二、三）**：
   - 身弱 → 喜 生扶（印星、比劫）；忌 克泄耗（官杀、食伤、财）。
   - 身强 → 喜 克泄耗（财、官杀、食伤）；忌 生扶（印、比劫）。
   - 中和 → 视组合酌取，寒暖燥湿为先。
   - **严禁"缺什么补什么"**：五行数量少≠喜用，须看日主需不需要（如身强忌印却印少，非喜）。引用 books.md 二·4 条件断语精神。

4. **调候用神**（books.md 五·穷通宝鉴）：
   - 冬生（亥子丑）→ 必用丙火暖局，寒极喜戊土止水。
   - 夏生（巳午未）→ 必用壬癸水润局。
   - 初春/深秋 → 余寒余燥，分别喜丙/喜水。
   调候为急，往往优先于扶抑。

5. **通关用神**：两行交战（如金木相战、水火相战）→ 取中间五行通关（金木战用水，水火战用木）。

6. **病药说**（books.md 四·渊海子平）：命局偏枯之字为"病"，制化之字为"药"；去病即贵。

输出旺衰结论时，给出：日主层级 + 得令/得地/得势 + 喜用神 + 忌神 + 调候，并说明五行哪个过旺/过弱。

## 第四阶段：格局派解读（月令取格 → 格局层次）

依据 `pattern` 与 `hidden_stems`（月支藏干透干情况），按《子平真诠》（books.md 一）：

1. **重定取格**：脚本给的是"月令本气"初步格。AI 须据 `hidden_stems.month` 检查月支藏干
   （本/中/余气）中**哪一个透出天干**（年/月/时干），以透出者为格；多透取力量大者；
   全不透则以本气取（杂气格）。说明"成格"依据。

2. **八格成败**（books.md 一·4）：
   - 用神（格星）是否有力、有相神护卫、无忌神破格。
   - 例：正官格见财印相随 → 成；正官见伤官无制 → 败；财格见比劫夺 → 败（须官杀护）。
   - 清/纯/真 → 层次高；浊/杂/假 → 层次低或有波折。

3. **格局与旺衰的关系**：
   - 格局派重"格局成败"定贵贱层次，不迷信身强；身弱而格成、用神得力亦可为贵。
   - 旺衰派重"日主能否担"；身弱格成须大运助身方发。
   - 两者结合：先定格局层次，再看日主强弱决定"何时能担"。

4. **特殊格局**（books.md 一·外格）：
   - 从格：日主极弱无根、满局皆异类 → 从强/从弱/从儿/从财/从官杀/从势（从格喜"从"，忌逆）。
   - 专旺：曲直（木）、炎上（火）、稼穑（土）、从革（金）、润下（水）——日主极旺、比劫林立。
   - 建禄/月刃/羊刃格、魁罡、日贵、金神、伤官伤尽、壬骑龙背等，按特征点出（脚本 `shensha` 已标魁罡等）。

5. **用神/相神/喜忌神**在此语境指"成格之用"，与旺衰派"扶抑用神"概念不同，须分别说明避免混淆。

## 第五阶段：神煞、纳音、大运流年（辅助与应期）

1. **神煞**（脚本 `shensha`）：天乙贵人（解危）、文昌（文采）、桃花（情缘/人际）、驿马（变动）、
   华盖（孤艺/玄学）、羊刃（刚烈/血光）、魁罡（果决）、空亡（力量打折/应期延迟）、十恶大败（祖业虚）。
   - 神煞只作意象辅助，**绝不可单凭神煞定吉凶**（books.md 六、七）。

2. **纳音**：年柱纳音为"本命"（如海中金命），可作气质/祖荫意象；纳音生克辅助，非主断。

3. **大运**（脚本 `dayun`）：
   - 顺逆、起运岁已由脚本算好。大运干支的十神即该运的"环境气场"。
   - 每一步大运：看运干（前五年重）与运支（后五年重）的十神、五行，对日主是喜是忌。
   - 喜用神大运 → 得志；忌神大运 → 困顿；原局病字被大运制化 → 去病得贵。

4. **流年**：`--liunian` 给出流年干支与十神。流年与四柱/大运发生刑冲合害、引动用神/忌神处 → 应期。
   - 流年天干司上半年、地支司下半年（传统）；流年冲提纲（月柱）→ 多变动。

## 第六阶段：综合论断流程（输出结构）

给用户的解读建议按此顺序组织：
1. **四柱与日主**：报四柱、日主、五行分布（1–2 句）。
2. **旺衰定底**：日主层级 + 得令得地得势 + 喜用神/忌神 + 调候。
3. **格局定层**：何格、成/败/清浊、用神相神。
4. **性格与六亲意象**：结合十神、神煞（贵人/羊刃/华盖等）。
5. **大运走势**：起运后几步关键大运的喜忌与阶段特征。
6. **所问专项**（事业/财/婚/学/健康）：用对应十神（官杀=事业，财=财，财官/官杀=婚，印=学，
   五行偏枯+忌神+冲克=健康隐患意象）做趋势化说明。
7. **诚实边界**：声明为文化研究/概率趋势，非宿命，重大决定以现实为准。

每条判断**标注依据**（出自哪个十神/神煞/旺衰要素/书籍），不编造、不用"必死/必发"等铁口词，
用"易/倾向于/利于/需注意/待冲实"等趋势化表达（参考 liuyao-najia 技能的表达纪律）。
