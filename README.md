# bazi.skill · 八字排盘与多派别解读

一个基于 [opencode](https://opencode.ai) / WorkBuddy 的八字（四柱命理）技能（skill）。
先做**真太阳时校正**，脚本精确排盘，AI 再按**网络公开内容**中的六步断法，及旺衰派、格局派、神煞/盲派/纳音等视角做趋势化文化解读。

> ⚠️ 声明：八字是传统文化与概率性趋势分析，**不构成任何命运、健康、投资、职业的预言或保证**。
> 本技能仅用于文化研究与娱乐参考，凡涉及人生重大决策请以现实情况并结合专业人士意见为准。

---

## 功能特性

- **真太阳时校正**（`scripts/truesolar.py`）
  - 北京时间 → 出生地真太阳时：经度差 + 均时差（NOAA 近似式，精度约 ±10 秒）
  - 内置 100+ 城市 / 市辖区经度表，也可直接给经度
  - **时辰边界风险分级**（余量 60 分钟为正中，<30 分钟必须并列两版结论）
  - 自动检测跨日（真太阳时落回前一天时，日柱须按前一天排）
- **精确排盘**（干支与节气由 [sxtwl 寿星天文历](https://github.com/yuwo11/sxtwl) 按天文历计算）
  - 四柱（年/月/日/时干支），以 **立春** 换年、**节气** 换月、**晚子时** 规则
  - **年干支以当年实测立春为界**：立春在 2/3–2/5 之间浮动（1900–2100 实测 39/128/34 年分布），代码按实测节气取，硬编码 2/4 会在 1980 这类 2/5 立春年出错
  - 天干十神、地支藏干（本气/中气/余气）及藏干十神
  - 五行旺衰统计与评分、日主强弱（得令/得地/得势）
  - **大运**（顺逆、起运岁数、干支序列）、流年十神
  - 神煞（天乙贵人、文昌、桃花、驿马、华盖、羊刃、魁罡、空亡、十恶大败等）
  - 六十甲子纳音（本命）
- **六步断法**（`references/liubu.md`，默认解读主线；取自网络公开的命理文章）
  - 流程：定盘 → 定旺衰 → 找病 → 取用神并评级 → 判大运 → 落六亲与应期
  - 六个可复用工具：病药优先于格局 / 用神「清而薄」三层评级 / 财分两笔（正财脆·偏财韧）/ 比劫夺财三形态 / 一神多用清单法 / 断语带反馈位
  - 含六亲逐项断法、断语输出模板、宝宝择时流程、9 条常见误判纠偏
- **派别校验层**：旺衰派（扶抑/调候/通关/病药）、格局派（子平真诠八格成败清浊）、神煞/纳音辅助
- **案例库**（`references/liubu_cases.md`）：18 个实盘案例（结构 + 断法要点 + 真实反馈），断完新盘后用于校准
- **经典知识库**：摘编自《子平真诠》《命运的求索》《滴天髓》《渊海子平》《穷通宝鉴》《三命通会》等公版/传统文献

## 自测

改动脚本后跑一遍回归测试，44 项断言覆盖立春日期（2/3、2/4、2/5 三种情形）、
立春交节时刻（2024/2025/1980，可与公开历表逐秒比对）、年柱换年边界（含 1980 立春
2/5 00:09:27 紧贴午夜的分钟级切换）、基准案例四柱、流年序列、真太阳时与时辰边界，
以及一项**独立交叉验证**（1900–2100 全 201 年的年干支对碰纯六十甲子算式，防"自洽地判错"）：

```bash
python scripts/selftest.py           # 简要
python scripts/selftest.py -v        # 逐项列出
```

全部通过输出 `OK`，任一失败以非零码退出。

> 写自测时的坑：`sxtwl.Time` 对象把时、分、秒分成 `h`、`m`、`s` **三个字段**，
> 不是"`h` 带小数"。按后者解析会得出 `16:00:00` 这类整点假象。

## 用法

### 1. 作为技能使用

将本仓库放入技能目录（如 `~/.workbuddy/skills/bazi/`），在对话中说：

> 「帮我排个八字，公历 1990 年 1 月 15 日 12:00，出生地北京，男」

技能会先校正真太阳时、判定时辰边界，再排盘，最后按 `references/liubu.md` 六步断法给出解读。

### 2. 命令行：先校正时辰

```bash
python scripts/truesolar.py --city 成都 --date 2000-01-01 --time 12:00
python scripts/truesolar.py --lon 104.07 --date 2000-01-01 --time 12:00 --json
```

输出示例（注意：西部城市修正量大，容易压到时辰边界）：

```text
出生地      成都  经度 104.07°E
北京时间    2000-01-01 12:00
经度差时    -63.72 分钟   (偏西为负→真太阳时更早)
均时差      -2.90 分钟
合计修正    -66.62 分钟
真太阳时    2000-01-01 10:53:22
时辰        巳时
边界余量    距最近边界 7.0 分钟 → 风险 极高（须核对钟点精确到分钟）
⚠️  可能落入 辰时 或 午时，请复核
排盘请用：-y 2000 -m 1 -d 1 -H 10 -M 53
```

### 3. 命令行：排盘

```bash
# 文本排盘（给人看的简版）
python scripts/bazi.py -y 1990 -m 1 -d 15 -H 12 -M 0 -s male

# 结构化排盘（推荐给 AI 读取解析）
python scripts/bazi.py -y 1990 -m 1 -d 15 -H 12 -M 0 -s male --json

# 查看指定年份起的流年十神
python scripts/bazi.py -y 1990 -m 1 -d 15 -H 12 -M 0 -s male --liunian 2026
```

参数说明：

| 参数 | 含义 | 示例 |
|------|------|------|
| `-y -m -d` | 公历出生年/月/日 | `-y 1990 -m 1 -d 15` |
| `-H -M` | 出生小时/分钟（24 小时制） | `-H 12 -M 0` |
| `-s` | 性别 `male` / `female` | `-s male` |
| `--no-night-zi` | 关闭「晚子时」规则（默认开启） | `--no-night-zi` |
| `--json` | 输出 JSON 结构化结果 | `--json` |
| `--liunian` | 显示从指定年份起的流年（含十神） | `--liunian 2026` |

> 时辰以出生地 **真太阳时** 为准；**请先跑 `truesolar.py` 再用其给出的参数排盘**。
> `23:00–23:59` 默认按「晚子时」规则排（时干取次日日干），可用 `--no-night-zi` 关闭。

## 设计原则

1. **先校时辰，再排盘。** 北京时间不是真太阳时，跨经度 + 均时差最大可差 ±30 分钟以上，足以换掉整根时柱。时辰错了，后面推得越细错得越远。
2. **排盘只由脚本确定性算出**，AI 不手推任何干支、藏干、大运、神煞。
3. **先找病，再取用神，后评层次。** 病不是"缺什么"，是"偏枯且无制"。药透则贵、药藏则平、药无则困。
4. **先看大运，再定格局。** 特殊格局要求"格局与大运同向"，否则格越纯摔得越重。
5. **用神要评级**（清而厚 / 清而薄 / 浊）——评级决定断语语气，这是敢下重话又不失准的关键。
6. **断语必须带时间点。** 不可验证的断语等于没断；不可校准则永远提高不了。
7. **每条结论标注依据**（哪个十神、哪个合冲、哪步大运），不编造、不铁口直断，用趋势化表达（易/倾向于/利于/需注意）。
8. **派别冲突如实呈现**（如旺衰派判身弱、格局派判格成），不强行归一。

## 断法速览（六步）

| 步 | 做什么 | 关键纪律 |
|---|---|---|
| 1 定盘 | 真太阳时校正 + 时辰边界风险 | 余量 <30 分钟必须并列两版结论 |
| 2 定旺衰 | 得令/得地/得势 | 必须说明"旺在哪"（比劫旺 or 印旺） |
| 3 找病 | 全盘最偏枯且无制之处 | 三问：有制？有泄？会被引动？ |
| 4 取用神 | 调候 > 病药 > 扶抑 | 取到后按清而厚 / 清而薄 / 浊评级 |
| 5 判大运 | 先运后格 | 特殊格局必须与运同向 |
| 6 落六亲 | 逐项断 + 应期 | 每条落到具体年份或大运 |

三个最能落地的推论工具：

- **财分两笔**：正财（工资）脆、易被劫；偏财（资产库）韧、能锁住 → 「涨薪改善不了处境，置产才行」。
- **比劫夺财三形态**：贴身劫 / 合被隔断（"差一步"）/ 财坐受克 → 三种现实对应完全不同。
- **用神清而薄**：格局干净但用神藏、无源、被克 → 降一层，且必须提前标出引动灾祸的流年。

## 数据来源与许可

- 排盘脚本 `scripts/bazi.py`：本仓库自研；干支/节气计算依赖 [sxtwl](https://github.com/yuwo11/sxtwl)（寿星天文历）。
- 真太阳时脚本 `scripts/truesolar.py`：本仓库自研；均时差采用 NOAA 近似式，无外部依赖。
- 五行/十神/藏干/纳音/神煞规则：传统命理公版常识。
- 方法论与典籍要点（`bazi_method.md`、`books.md`）：摘编自《子平真诠》《命运的求索》《滴天髓》《渊海子平》《穷通宝鉴》《三命通会》等公版/传统文献，仅作文化研究参考，不复制任何 NonCommercial 授权内容。
- 断法手册（`liubu.md`）与案例库（`liubu_cases.md`）：由**网络公开的命理文章**的写作范式与判断方法归纳而来，属方法层面的抽象总结，**不转载原文、不复制其命盘表格与正文**；案例库每条仅保留"结构特征 + 断法要点 + 反馈结果"三要素用于方法校准。原文著作权归原作者。
